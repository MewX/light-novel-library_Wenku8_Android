# LightNovelLibrary `v0.5.2.1` 典藏版（历史归档）

本目录为 `0.5.x` 经典老版（典藏版）的最终历史源码归档（原仓库根目录 `eclipse-android-old/`）。

## 版本信息

- **包名**：`org.mewx.lightnovellibrary`
- **版本号**：`versionName = 0.5.2.1`（`versionCode = 9`）
- **目标 SDK**：`minSdkVersion 10`（Android 2.3.3） / `targetSdkVersion 22`（Android 5.1）
- **工程形态**：由 Eclipse ADT 迁移至早期 Android Studio / Gradle 的多模块工程（`LightNovelLibrary/` + `appcompat_v7/`）

## 说明

- 相较后续的 `1.x` Material Design 版本，典藏版结构轻量、在早期旧机型上启动与运行更为流畅，第三方库主要以源码拷贝/合并或本地 JAR 方式集成。
- 归档整理时已清理历史上误提交的 `build/`、`LightNovelLibrary/build/` 与 `appcompat_v7/build/` 编译中间产物，仅保留源码与工程配置。
- 预览截图与 Fireworks 图片源文件分别位于 [`../../screenshots/v0/`](../../screenshots/v0/) 与 [`../../graph_sources/`](../../graph_sources/)。
