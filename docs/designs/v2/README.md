## Key Highlights of the `v2.0` Redesign

1. **Authentic Material 3 Expressive (`M3e`) + Familiar 4-Tab Structure (`最新` Default)**:
   - Uses M3e `ShortNavigationBar` (`64.dp`) on phones and `WideNavigationRail` on foldables/tablets while preserving `v1.31`'s exact 4 primary destinations (**`书架 · 最新 · 排行 · 我的`**), booting into **`最新` (`Latest`)** by default with a user setting to make **`本地书架`** the default home (plus smart offline fallback) and **100% preservation of all existing `v1.31` settings**.
2. **Seamless Play Store Upgrade & Atomic Room SQLite (`wenku8_v2.db`)**:
   - Automatically migrates internal storage (`filesDir/saves/settings.wk8`, `cert.wk8`, `bookshelf_local.wk8`, `intro/*.xml`, `novel/*.xml`, `read_saves*.wk8`, `search_history.wk8`) on `org.mewx.wenku8` upgrade while keeping `saves/imgs/` & `custom/` assets live in place; synchronizes TOC updates via single-`@Transaction` `@Upsert` + monotonic `toc_version` checks.
3. **Default-On `"自动优化连接"` (Compact 18-Probe Tournament) & Transparent `网络检测`**:
   - Screens and confirms faster verified Cloudflare ingress IPs in ~10–14s when foreground I/O is idle (and recovers blocked default routes within 20s), paired with a 1-tap `NetworkDiagnosticsScreen` and privacy-first report sharing.
4. **Sustainable, Non-UX-Harming Server Support**:
   - Retains a single zero-CLS, lazy-initialized inline banner slot exclusively on `NovelDetailScreen` between Synopsis and Volume Accordions (100% absent from the Reader and Bookshelf, collapsing cleanly offline or without Play Services).
